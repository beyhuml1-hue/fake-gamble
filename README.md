# DonutFlip

Play-money arcade. The balance is **coins** with no cash value. There is no real deposit, no withdrawal, and no real-money gambling.

## Play

```bash
npm install
npm run dev
```

Open the local URL Vite prints. You start with $1,000.00. Refill or set a practice balance from Wallet. Everything stays in this browser.

## Games

Dice, Mines, Plinko, Crash, Limbo, Keno, Wheel, Hi-Lo, Blackjack, Roulette, Dragon Tower, Flip, and Diamonds. Every table uses the same bet ticket. Originals are built to a 99% return except European roulette, which keeps the single-zero wheel.

This is a simulator. It is not a real-money casino and it is not affiliated with any gambling brand.
